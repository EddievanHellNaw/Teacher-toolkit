# Django Teacher Toolkit

Django Teacher Toolkit is an educational web application designed to help teachers manage students, grades, quizzes, and classroom data.

## Purpose

This project was created as part of my Python and Django teaching portfolio. It demonstrates practical software development concepts such as models, views, templates, forms, CRUD operations, and database relationships.

## Planned Features

- Student management
- Group management
- Gradebook
- Quiz platform
- Teacher dashboard

## Technologies

- Python
- Django
- SQLite
- HTML
- CSS
- Bootstrap
